# Pension / Investment Risk Dashboard

Status: scaffolded for Sprint 4.

This project will model retirement and investment portfolio analytics with synthetic data for asset allocation, returns, drawdown, volatility, risk profiles, FX exposure, duration proxy, contribution growth, retirement projections, and stress scenarios.

Target roles supported:
- Investment Risk Analyst
- Financial Data Analyst
- Treasury / Risk Reporting Analyst
- BI Analyst - Finance
