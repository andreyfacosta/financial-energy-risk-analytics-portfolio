# Drilling Project Controls Interview Questions

## Questions to Practice

- How do AFE budget and forecast final cost differ?
- What does schedule variance show?
- How do NPT and rig utilization affect project performance?
- How would a project manager use the dashboard?
- How did you model contractor performance?
- What would you improve with real daily drilling reports?

## Short Answer Themes

- Forecast final cost estimates where the well may land based on current progress.
- NPT helps explain whether schedule/cost issues are operational, logistical, mechanical, or contractor-driven.
- HSE indicators should be reviewed alongside cost and schedule, not separately.
