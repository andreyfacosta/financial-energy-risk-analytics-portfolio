# Power BI, SQL, and Python Interview Questions

## Power BI

- How do you decide which tables are dimensions and facts?
- Why use a calendar table?
- How do DAX measures differ from calculated columns?
- How would you validate dashboard totals?
- How do slicers and relationship direction affect results?

## SQL

- Explain a join used in one project.
- Why create SQL views after analytical outputs?
- How would you optimize this model for larger data?
- How would you validate row counts and totals?

## Python

- Why use pandas for the analysis layer?
- How do you avoid confidential data in a portfolio?
- How would you make the scripts production-ready?
- How would you test metric calculations?

## Answer Themes

- Keep raw data, analytical outputs, and BI measures separated.
- Validate totals against summary tables and source row counts.
- Use synthetic data for public portfolio work and never include secrets.
