# Portfolio Pitch

## 60-Second Version

I built a four-project Financial & Energy Risk Analytics portfolio to show how I connect business risk questions with Python, SQL, pandas, SQLite, and Power BI-ready reporting.

The projects cover commodity hedge risk, drilling project controls, insurance loss ratio, and pension investment risk. Each project uses synthetic data, so there is no confidential employer information. Each one includes raw data, analytical outputs, SQL schema, SQL views, DAX measures, Power BI build guide, README, demo script, and recruiter-facing career assets.

The portfolio reflects my background in financial markets and risk, Canadian finance/commodity experience, and petroleum operations experience.

## 2-Minute Version

My portfolio is designed for remote Financial Data Analyst, Risk Reporting Analyst, BI Analyst, Commodity Risk Analyst, Energy Data Analyst, Insurance Data Analyst, and Investment Risk roles.

Project 1 models commodity hedge risk for a Canadian grain company scenario. Project 2 models drilling project controls for oilfield operations. Project 3 models group insurance loss ratio and renewal risk. Project 4 models pension investment risk and retirement projections.

The common workflow is: generate synthetic but realistic data, model it in SQL/SQLite, calculate KPIs with Python and pandas, export Power BI-ready CSVs, document DAX measures, and design executive dashboard pages.

This shows I can move from business problem to data model to analytics output to executive communication.
