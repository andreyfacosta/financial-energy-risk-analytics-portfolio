# Pension Investment Risk Interview Questions

## Questions to Practice

- How did you calculate portfolio value?
- What is active return?
- Why are volatility and drawdown both useful?
- How does FX exposure affect a CAD retirement portfolio?
- What assumptions are used in the retirement projection?
- How would you improve the project with real data?

## Short Answer Themes

- Active return compares portfolio return against benchmark return.
- Drawdown explains downside path risk; volatility explains variability.
- Retirement projections are simplified and should be explained as planning scenarios, not financial advice.
