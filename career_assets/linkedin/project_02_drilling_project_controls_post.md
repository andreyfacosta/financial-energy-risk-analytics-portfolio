## Technical Post

I built a synthetic drilling project controls analytics project to model how an oilfield operations team might monitor cost, schedule, NPT, rig utilization, contractor performance, and HSE risk.

The workflow includes Python data generation, SQLite schema design, SQL views, pandas analysis, Power BI-ready CSV outputs, DAX measures, and a six-page Power BI build guide.

The dashboard pages are Executive Summary, Budget vs Actual, Schedule & NPT, Rig / Contractor Performance, HSE & Operational Risk, and Well Detail.

The goal is to show how operational field data can be turned into executive reporting that helps identify wells at risk before overruns become surprises.
