# LinkedIn Featured Project Description

## Commodity Hedge Risk Dashboard

I built a synthetic commodity risk analytics project for a Canadian grain company scenario. The project models physical grain transactions, futures hedges, cash and futures prices, FX rates, margin requirements, counterparties, and calendar data.

The dashboard design tracks physical exposure, futures exposure, net open exposure, hedge ratio, basis risk, daily and cumulative P&L, margin requirements, VaR approximation, stress test impact, counterparty exposure, and risk flags.

Tools used:
- Python
- pandas
- SQL / SQLite
- Power BI model design
- DAX measure planning

Business value:
- Helps risk teams monitor hedge effectiveness.
- Highlights exposure and margin pressure.
- Supports executive reporting for commodity risk decisions.
- Demonstrates practical financial and commodity risk analytics using reproducible synthetic data.
