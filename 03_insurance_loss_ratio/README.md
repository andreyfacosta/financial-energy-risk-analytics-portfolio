# Insurance / Group Policy Loss Ratio Dashboard

Status: scaffolded for Sprint 3.

This project will model group insurance analytics with synthetic data for premiums, claims, members, loss ratio, claims frequency, claims severity, profitability, renewal risk, high-risk groups, and product/category trends.

Target roles supported:
- Insurance Data Analyst
- Financial Data Analyst
- Risk Reporting Analyst
- BI Analyst - Finance
