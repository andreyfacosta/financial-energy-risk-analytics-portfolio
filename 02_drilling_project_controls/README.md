# Drilling Operations / Project Controls Dashboard

Status: scaffolded for Sprint 2.

This project will model oilfield/drilling operations with synthetic data for AFE budget vs actual cost, schedule variance, drilling days, non-productive time, rig utilization, cost per foot, HSE incidents, contractor performance, forecast final cost, and risk flags.

Target roles supported:
- Energy Data Analyst
- Operations Data Analyst
- Project Controls Data Analyst
- BI Analyst - Operations
