# DAX Measures

Create a disconnected `Measures` table in Power BI Desktop and add these measures. Column names match the CSV outputs generated by this project.

## Format Recommendations

| Measure type | Suggested format |
|---|---|
| CAD values | Currency, CAD, 0 decimals |
| Percentages | Percentage, 1-2 decimals |
| Days/hours/meters | Decimal number, 1-2 decimals |
| Counts | Whole number |

## Cost Measures

```DAX
AFE Budget CAD =
SUM ( well_performance_summary[afe_budget_cad] )

Actual Cost CAD =
SUM ( well_performance_summary[actual_cost_cad] )

Daily Actual Cost CAD =
SUM ( daily_project_metrics[actual_cost_cad] )

Cumulative Actual Cost CAD =
SUMX (
    VALUES ( daily_project_metrics[well_id] ),
    VAR LatestWellDate =
        CALCULATE ( MAX ( daily_project_metrics[date] ) )
    RETURN
        CALCULATE (
            MAX ( daily_project_metrics[cumulative_actual_cost_cad] ),
            daily_project_metrics[date] = LatestWellDate
        )
)

Latest Cumulative Actual Cost CAD =
[Cumulative Actual Cost CAD]

Forecast Final Cost CAD =
SUM ( well_performance_summary[forecast_final_cost_cad] )

Latest Forecast Final Cost CAD =
SUMX (
    VALUES ( daily_project_metrics[well_id] ),
    VAR LatestWellDate =
        CALCULATE ( MAX ( daily_project_metrics[date] ) )
    RETURN
        CALCULATE (
            MAX ( daily_project_metrics[forecast_final_cost_cad] ),
            daily_project_metrics[date] = LatestWellDate
        )
)

Forecast Variance CAD =
SUM ( well_performance_summary[forecast_variance_cad] )

Cost Variance CAD =
SUM ( well_performance_summary[forecast_variance_cad] )

Cost Variance % =
AVERAGE ( well_performance_summary[cost_variance_pct] )

Cost per Meter CAD =
AVERAGE ( daily_project_metrics[cost_per_meter_cad] )
```

## HSE and Risk Measures

```DAX
HSE Incident Count =
SUM ( daily_project_metrics[hse_incident_count] )

Recordable Count =
SUM ( daily_project_metrics[recordable_count] )

Lost Time Count =
SUM ( daily_project_metrics[lost_time_count] )

High Risk Days =
CALCULATE (
    COUNTROWS ( daily_project_metrics ),
    daily_project_metrics[risk_flag] = "High"
)

Medium Risk Days =
CALCULATE (
    COUNTROWS ( daily_project_metrics ),
    daily_project_metrics[risk_flag] = "Medium"
)

High Risk Wells =
CALCULATE (
    DISTINCTCOUNT ( well_performance_summary[well_id] ),
    well_performance_summary[risk_flag] = "High"
)
```

## Validation Notes

- `Forecast Final Cost CAD` should reconcile to `executive_project_controls_summary.csv`.
- `HSE Incident Count` should reconcile to `hse_summary.csv`.
- `NPT Hours` should reconcile to `npt_summary.csv`.
- Use `well_performance_summary` for final well-level KPI cards and `daily_project_metrics` for trends.
- Do not use a simple `MAX ( daily_project_metrics[cumulative_actual_cost_cad] )` for portfolio-level cards; it returns only the largest single-well cumulative cost, not the sum across wells.
- `Cumulative Actual Cost CAD` and `Latest Forecast Final Cost CAD` intentionally iterate by `well_id` and pull each well's latest available daily value before summing.
- For date-axis trend visuals, use `Daily Actual Cost CAD`, `NPT Hours`, `Rig Utilization %`, and other daily measures from `daily_project_metrics`.
