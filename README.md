# Financial & Energy Risk Analytics Portfolio

Portfolio of financial, commodity, energy, and operations risk analytics projects using Python, SQL, pandas, and Power BI.

This repository is designed for remote Canada/global roles such as Financial Data Analyst, Risk Reporting Analyst, BI Analyst, Energy Data Analyst, Commodity Risk Analyst, Operations Data Analyst, Insurance Data Analyst, Treasury/Risk Reporting Analyst, and FP&A Analyst with Power BI.

## Why This Portfolio Exists

My background combines financial markets and risk education, Canadian finance and commodity exposure, and older oilfield operations leadership experience. The goal of this portfolio is to show practical analytics work that connects business risk, operational decisions, SQL/Python data preparation, and Power BI-ready reporting.

## Projects

| Project | Business focus | Status | Main skills shown |
|---|---|---:|---|
| 01 Commodity Hedge Risk Dashboard | Grain physical exposure, futures hedges, basis, P&L, margin, stress testing | v1 complete | Python, pandas, SQL, risk metrics, Power BI model design |
| 02 Drilling Project Controls | Planned vs actual cost, schedule variance, NPT, rig utilization, HSE | Scaffolded | Operations analytics, project controls, dashboard design |
| 03 Insurance Loss Ratio | Premiums, claims, loss ratio, renewal risk, profitability | Scaffolded | Insurance analytics, cohort trends, KPI reporting |
| 04 Pension Investment Risk | Allocation, returns, drawdown, volatility, FX exposure, scenarios | Scaffolded | Investment risk, portfolio analytics, retirement scenarios |

## Quick Start

```powershell
python -m pip install -r requirements.txt
python 01_commodity_hedge_risk/notebooks/01_generate_synthetic_data.py
python 01_commodity_hedge_risk/notebooks/02_analyze_hedge_risk.py
```

Generated CSV files are stored under `01_commodity_hedge_risk/data/` and can be imported into Power BI.

## Data Notice

All datasets are synthetic and realistic by design. No confidential employer data, credentials, paid APIs, or private information are used.
